## Overview

Compressed Creativity is a Minecraft mod that adds machines to convert between Create's rotational force and PneumaticCraft's compressed air systems. It enables exciting new automation possibilities by bridging these two powerful tech mods.

## Features

### Machines
- **Rotational Compressor** - Converts Create rotational force into PneumaticCraft compressed air
- **Compressed Air Engine** - Converts PneumaticCraft compressed air into Create rotational force
- **Air Blower** - Uses compressed air to create Create-style air currents
- **Industrial Air Blower** - Advanced air blower with mesh support for processing items
- **Heater** - Heat exchanger block for thermal integration

### Items
- **Mesh Types** - Various meshes for the Industrial Air Blower (Water Soaked, Woven, Dense, Haunted)
- **Mechanical Visor Upgrade** - PneumaticCraft helmet upgrade for viewing Create goggle information
- **Crafting Materials** - Engine Rotor, Brass Gilded Lapis, Brass Coated Upgrade Matrix

### Blocks
- **Bracketed Pressure Tubes** - Pressure tubes with Create-style brackets
- **Colored Plastic Brackets** - Decorative brackets in all 16 colors
- **Compressed Iron Casing** - Industrial-themed casing block

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1+
- Create 0.6+
- PneumaticCraft: Repressurized

## Building

```bash
./gradlew build
```

The built JAR will be in `neoforge/build/libs/`.
